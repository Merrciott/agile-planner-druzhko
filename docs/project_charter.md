# Основания и назначение разработки

## Основание

Проект выполняется как рейтинговая работа по дисциплине «Проектная деятельность в ИТ». Вариант по букве «Д» фамилии Дружко - личный Agile-планировщик.

## Проблема

При ведении личных задач в нескольких заметках трудно видеть общий объём работы, ограничивать текущий спринт и понимать, сколько уже завершено. Для учебного проекта достаточно одного локального интерфейса без регистрации и сервера.

## Цель

Создать работающий прототип, в котором пользователь сможет собрать бэклог, выбрать задачи на спринт, менять их статус и оценивать прогресс.

## Пользователь и результат

Основной пользователь - один человек, планирующий собственную учёбу или небольшой проект. Результат - статическая веб-страница с доской задач, локальным сохранением и резервным копированием данных. Разработку можно открыть прямо из файла `index.html`.

## Границы проекта

В проект включены задачи, статусы, приоритеты, условные баллы, цель и даты спринта, поиск, фильтр и экспорт/импорт. Совместное редактирование, уведомления, интеграция с календарём и серверное хранение оставлены за пределами учебного прототипа.

## Критерий завершения

Пользователь может создать задачу, перенести её через статусы до «Готово», закрыть и вновь открыть страницу без потери данных, а также выгрузить и восстановить задачи из JSON. Основные сценарии описаны в `test_plan.md`.
