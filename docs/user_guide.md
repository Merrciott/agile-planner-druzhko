# Инструкция пользователя

## Начало работы

Откройте `index.html` в браузере. Чтобы посмотреть интерфейс с примерами, нажмите «Загрузить пример». Образец заменяет пустые данные только после подтверждения.

## Настройка спринта

Заполните название, цель, даты начала и окончания и нажмите «Сохранить спринт». Дата окончания должна быть не раньше даты начала.

## Задачи

Введите название задачи, при необходимости описание, выберите приоритет и оценку. Выберите, включать ли задачу в текущий спринт. После создания она появится в бэклоге либо в колонке «К выполнению».

Карточку можно перемещать кнопками «Назад» и «Далее», изменять через «Редактировать» или удалять после подтверждения. Поиск и фильтр меняют только видимый список; сохранённые задачи остаются.

## Резервная копия

Нажмите «Экспорт JSON», чтобы сохранить копию задач и настроек спринта. Для восстановления выберите файл через «Импорт JSON». Перед заменой текущего набора программа спросит подтверждение.

## Ограничения

Данные находятся в хранилище текущего браузера. При очистке данных сайта они могут исчезнуть. Для переноса на другой компьютер сначала экспортируйте JSON, затем импортируйте его там.
