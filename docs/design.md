# Проектирование прототипа

## Логика экрана

Страница состоит из четырёх зон: обзор спринта, форма задачи, параметры спринта и доска из четырёх колонок. Пользователь сначала задаёт цель спринта, затем добавляет задачи и наблюдает показатели. Бэклог хранит задачи вне текущего спринта. Кнопки на карточке меняют статус на один шаг назад или вперёд.

## Архитектура

Прототип не имеет сервера. `index.html` задаёт структуру, `styles.css` - оформление и адаптацию к экрану, `app.js` - проверку ввода, состояние, отрисовку, локальное сохранение и резервные копии. Вся информация хранится в одном объекте версии 1. Входящий JSON проверяется до замены текущих данных.

## Структура данных

Спринт: название, цель, даты начала и окончания. Задача: идентификатор, название, описание, приоритет, баллы, статус, признак участия в спринте и время создания. Признак участия согласован со статусом: задачи в бэклоге вне спринта, задачи в других колонках входят в него.

## Доступность и безопасность

У каждого поля есть подпись. События доступны через обычные кнопки и формы. Пользовательский текст выводится как текст с помощью `textContent`; он не вставляется как HTML. Отчётливые состояния фокуса помогают работать клавиатурой. Экспорт нужен, потому что `localStorage` не заменяет резервную копию.
