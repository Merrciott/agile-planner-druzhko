# Требования к личному Agile-планировщику

## Пользовательские сценарии

| ID | Сценарий | Критерий приёмки |
| --- | --- | --- |
| US-01 | Как пользователь, я добавляю задачу в бэклог или текущий спринт | Новая карточка появляется в нужной колонке и остаётся после обновления страницы |
| US-02 | Я задаю приоритет и оценку задачи | Карточка показывает выбранные значения |
| US-03 | Я перемещаю задачу между этапами | Статус меняется, а счётчики пересчитываются |
| US-04 | Я редактирую или удаляю задачу | Изменение сохраняется; перед удалением запрашивается подтверждение |
| US-05 | Я задаю цель и даты спринта | Настройки отображаются после повторного открытия страницы |
| US-06 | Я ищу задачи и фильтрую их по приоритету | Показаны только подходящие карточки; данные не удаляются |
| US-07 | Я создаю резервную копию и восстанавливаю её | JSON-файл содержит задачи и спринт; после импорта данные появляются в интерфейсе |

## Функциональные требования

1. Задача содержит идентификатор, заголовок, описание, приоритет, оценку, принадлежность к спринту и статус.
2. Заголовок обязателен, имеет длину от 1 до 100 символов. Оценка выбирается из набора 1, 2, 3, 5, 8, 13.
3. Доступны четыре статуса: бэклог, к выполнению, в работе, готово.
4. Для задачи текущего спринта показываются действия перехода между этапами. Задачу можно вернуть в бэклог.
5. Прогресс считается по задачам текущего спринта: число завершённых задач и сумма завершённых баллов относительно запланированных.
6. Данные сохраняются после каждого изменения в хранилище браузера.
7. Импорт отвергает файл с неправильной структурой и не заменяет текущие данные до успешной проверки.

## Нефункциональные требования

- Прототип работает локально без сети и без установки пакетов.
- Интерфейс пригоден для настольного и мобильного экрана.
- Поля формы имеют видимые подписи, а действия доступны с клавиатуры.
- Пользовательский текст вставляется в страницу как текст, а не как HTML.
- Данные остаются на одном устройстве; для переноса используется экспорт JSON.

## Модель данных

Задача: `id`, `title`, `description`, `priority`, `points`, `status`, `inSprint`, `createdAt`. Спринт: `name`, `goal`, `startDate`, `endDate`. Все записи находятся в одном объекте версии 1, который сохраняется в `localStorage` и экспортируется в JSON.
